## Rule for every new idea

Ask:
1. Does this materially improve impact?
2. Does this improve feasibility?
3. Does this improve community rootedness?
4. Does this strengthen theme alignment?
5. Does this improve team credibility?
6. Does this make the demo clearer?

If the answer is **no to all six**, put it in the post-submission backlog.
