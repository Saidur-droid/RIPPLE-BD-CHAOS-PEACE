# RIPPLE BD — CHAOS → PEACE

> **Every click has a consequence.**

RIPPLE BD is a mobile-first digital peace simulator for Bangladeshi youth. It lets participants experience how online harm spreads, rewind the consequences, practise safer responses, and measure whether those digital peacebuilding reflexes last.

This repository is being developed for the **DKC Digital Respect & Cohesion Fellowship 2026**.

## Core product thesis

> People learn digital peacebuilding more deeply when they can safely experience the consequences of a decision, reverse it, practise a better response, and see what changed.

## Core loop

**MIRROR → RIPPLE → HUMAN CONSEQUENCE → REWIND → PEACE → REFLECT → RETAIN**

## MVP

The first MVP is a **6–8 minute, mobile-first web experience** with:
- three fictional Bangladesh-relevant scenarios,
- baseline decision capture,
- Ripple Engine,
- REWIND,
- SHIELD Mode,
- Manipulation X-Ray,
- Digital Reflex Profile,
- booster-ready retention flow,
- zero paid APIs/services.
