# RIPPLE BD — CHAOS → PEACE

> **Every click has a consequence.**

RIPPLE BD is a mobile-first digital peace simulator for Bangladeshi youth. It lets participants experience how online harm spreads, rewind the consequences, practise safer responses, and measure whether those digital peacebuilding reflexes last.

This repository is being developed for the **DKC Digital Respect & Cohesion Fellowship 2026**.

The full product, research, pilot, safeguarding, execution, team, and pitch blueprint is maintained in this repository.
