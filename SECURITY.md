# Security & Privacy

## Scope

The pre-submission MVP is intentionally low-risk and static-first.

## Data we do not need

Do not collect:
- passwords,
- NID/passport,
- phone numbers,
- precise location,
- social-media credentials,
- sensitive images,
- harassment evidence from real incidents,
- political or religious preference.

## Pilot identity

Use random participant codes for optional follow-up.

## Sensitive disclosures

If a participant voluntarily discloses a real harmful experience:
- do not copy it into the app/repo,
- do not promise investigation,
- respond according to the pilot safeguarding protocol,
- direct them toward appropriate trusted/official help if needed.

## Vulnerability reporting

Until a dedicated security contact is established, report security issues privately to the repository owner rather than opening a public issue containing exploit details or participant data.

## Secrets

No API keys or secrets should be required for the static MVP.
Never commit credentials to the repository.
